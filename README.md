---

## Vision du Projet

Ampheria est le client mobile (Flutter) du projet **AmikOne**. C'est un PoC visant à créer une alternative aux applications de rencontre traditionnelles (type Tinder) en misant sur la **transparence totale**.

> [!IMPORTANT]
> **État du projet : Laboratoire d'idées**
> Le projet est actuellement un regroupement de tests de fonctionnalités. Il ne doit pas être considéré comme une application stable à long terme, mais comme un terrain d'expérimentation pour de nouveaux concepts de rencontre libre.

---

## Fonctionnalités Clés

- **Décentralisation & Multi-instances** : Choisissez votre instance Supabase parmi une liste communautaire (chargée via GitHub) ou configurez votre propre serveur personnalisé.
- **Système de Match (Swipe/Like)** : Une interface intuitive pour découvrir et liker des profils.
- **Messagerie Temps Réel** : Discutez instantanément avec vos matchs.
- **Identité Avancée** : Gestion complète du profil (Bio, Passions, Galerie Photos) et personnalisation fine de l'identité (Genre, Orientation, Préférences).
- **Géolocalisation** : Trouvez des personnes à proximité selon vos critères de distance.

---

## Stack Technique
- **Framework** : [Flutter](https://flutter.dev/)
- **Backend** : [Supabase](https://supabase.com/) (Auth, Database, Storage, Edge Functions)
