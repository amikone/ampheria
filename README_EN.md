# Ampheria (AmikOne)

[FR](README.md)

> **The Open-Source client for free, transparent, and community-supported dating.**

---

## Project Vision

Ampheria is the mobile client (Flutter) for the **AmikOne** project. It is a PoC (Proof of Concept) aimed at creating an alternative to traditional dating applications (like Tinder) by focusing on **total transparency**.

> [!IMPORTANT]
> **Project Status: Idea Lab**
> The project is currently a collection of feature tests. It should not be considered a stable, long-term application, but rather a testing ground for new concepts in free dating.

---

## Key Features

- **Decentralization & Multi-instances**: Choose your Supabase instance from a community list (loaded via GitHub) or configure your own custom server.
- **Match System (Swipe/Like)**: An intuitive interface to discover and like profiles.
- **Real-Time Messaging**: Chat instantly with your matches.
- **Advanced Identity**: Complete profile management (Bio, Passions, Photo Gallery) and fine-tuned identity customization (Gender, Orientation, Preferences).
- **Geolocation**: Find people nearby based on your distance criteria.

---

## Technical Stack
- **Framework**: [Flutter](https://flutter.dev/)
